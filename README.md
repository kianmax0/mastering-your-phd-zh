# 《掌控你的博士生涯》在线读本

《掌控你的博士生涯：博士岁月及未来的生存与成功》的中文在线阅读站。

**在线阅读：** <https://kianmax0.github.io/mastering-your-phd-zh/>

## 功能

- 完整章节目录与全文搜索
- 自动记录阅读进度和最后阅读位置
- 亮色、护眼和深色三种主题
- 三档正文字号
- 桌面端、平板和手机自适应
- 上一章／下一章快速导航

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm ci
npm run dev
```

提交到 `main` 分支后，GitHub Actions 会自动生成静态版并发布到 GitHub Pages。
